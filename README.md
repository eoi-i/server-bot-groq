# GLOBALHOLMES LTD — Telegram AI Bot

بوت ذكاء اصطناعي عربي/متعدد اللغات باستخدام Groq والنموذج `openai/gpt-oss-120b`، مع حفظ سجل المحادثات والمستخدمين في PostgreSQL.

## المتغيرات المطلوبة

أضفها كـ Fly secrets ولا تضع المفاتيح داخل الملفات:

- `TELEGRAM_TOKEN`: توكن البوت من BotFather.
- `GROQ`: مفتاح Groq. هذا هو الاسم الظاهر في لقطة الشاشة. يدعم المشروع أيضاً `GROQ_API_KEY` كاسم بديل.
- `DATABASE_URL`: رابط PostgreSQL.

## النشر على Fly.io

1. فك ضغط المشروع وافتح الطرفية داخل مجلده.
2. سجّل الدخول: `fly auth login`
3. أنشئ التطبيق أو اربطه باسم متاح: `fly launch --no-deploy`
   - إذا أنشأت التطبيق بهذه الخطوة، راجع `fly.toml` واجعل `app` مطابقاً للاسم الذي اخترته.
4. أضف الأسرار:

```bash
fly secrets set TELEGRAM_TOKEN="توكن_تلغرام" GROQ="مفتاح_Groq" DATABASE_URL="رابط_PostgreSQL"
```

5. انشر:

```bash
fly deploy
```

6. افحص السجلات:

```bash
fly logs
```

وفحص الصحة من عنوان تطبيق Fly سيعيد JSON بحالة `ok` على `/health`.

## قاعدة البيانات

ينشئ البوت الجداول والفهارس تلقائياً عند أول تشغيل. لا يحتاج إلى تشغيل SQL يدوياً. يجب أن تكون قاعدة PostgreSQL متاحة من تطبيق Fly وأن يشير `DATABASE_URL` إلى قاعدة صحيحة.

إذا كانت قاعدة البيانات تتطلب SSL صراحةً، أضف السر:

```bash
fly secrets set DATABASE_SSL=require
```

## الأوامر والأزرار

- `/start` تشغيل وترحيب.
- `/new` محادثة جديدة ومسح السياق السابق.
- `/clear` حذف سجل محادثة المستخدم الحالية.
- `/about` معلومات عن المساعد.
- `/help` التعليمات.

الأزرار المضمنة تظهر بأسلوب Telegram القياسي؛ لا يتيح Bot API التحكم بشفافية الزر أو ألوانه يدوياً.

## ملاحظات

- لا تشارك `TELEGRAM_TOKEN` أو `GROQ` أو `DATABASE_URL` مع أحد.
- لا ترفع ملف `.env` أو المفاتيح إلى GitHub.
- احتفظ بنسخة احتياطية من PostgreSQL إذا كانت المحادثات مهمة.
- البوت يستخدم Long Polling، لذلك لا يحتاج إلى إعداد Webhook أو نطاق خاص.
